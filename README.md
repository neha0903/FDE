3. Git Fetch vs Git Pull
git fetch
Gets the latest changes from GitHub.
Does not change your current code.
Let me see what's new."
git pull
Gets the latest changes from GitHub.
Also updates your local branch with those changes.
"Get what's new and update my code"
git fetch downloads the latest changes from the remote repository without changing my working branch. git pull downloads the changes and merges them into my current branch."
